功能描述
================================================================================
说明：
This example mainly demonstrates the function of USB simulated serial communication. 
The serial communication parameters (port, baud rate, data bits, parity bits, stop 
bits) are set by the host computer. After connection, data is sent to the MCU through
 the host computer's serial port debugging assistant. When the MCU receives the last 
data as 0x0d, it will send back a string to the host computer.

================================================================================
使用步骤
================================================================================
1）打开工程并重新编译；
2）启动IDE的下载和调试功能；
3）运行;
4）通过上位机将识别到两个COM口，通过上位机串口调试助手连接任意一个，向MCU发送数据，
所发送的数据以0x0d作为结束符，MCU接收到数据时将发送出如下字符串：
"This is a sample about usb cdc_1ep"或"This is a sample about usb cdc_3ep",
